# NuCI 0.2.0

NuCI is a web interface for OpenWrt 25.12 that does not use or depend on LuCI.
0.2 adds the first apps, German and Simplified Chinese, non-root users, and
removes the size limits of 0.1.

## Install

```sh
# on the router (OpenWrt 25.12, apk; any architecture)
BASE=https://github.com/giejqf/nuci/releases/download/v0.2.0
wget -O /etc/apk/keys/nuci-feed.pem "$BASE/nuci-feed.pem"
echo "$BASE/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add nuci                      # the interface
apk add nuci-app-wireguard        # optional apps, see below
```

Then open `http://<router>/nuci/`. Upgrading from 0.1: `apk update && apk upgrade`
after replacing the repository line with the 0.2.0 one.

## New

- **Apps.** Install as separate packages; each pulls in its OpenWrt backend:
  - `nuci-app-wireguard`: WireGuard tunnels and peers, keys generated on the
    router, peer configuration export with QR code.
  - `nuci-app-ddns`: Dynamic DNS services (ddns-scripts' 60+ providers or a
    custom URL) with status and log.
  - `nuci-app-upnp`: UPnP/NAT-PMP settings, access rules and the port
    mappings devices requested.
  - `nuci-app-sqm`: smart queue management (cake / fq_codel) against
    bufferbloat, with the active shaping per interface.
- **Languages.** German and Simplified Chinese, chosen from the browser or
  in the top bar; numbers, sizes, dates and durations follow the language.
- **Users.** System → Users adds logins with a role (administrator,
  operator, read-only) or custom permission groups. Limited users see only
  what they may use; the router enforces the same rules. Root is unchanged.
- **No size limits for backups and firmware.** Backups of any size download
  and restore; firmware uploads in one request (ADR-0005).
- **More network features.** 6in4, 6rd and DS-Lite interfaces (offered when
  installed); bridge VLAN filtering for DSA switches and bridges.
- **App platform.** `@nuci/app-sdk` 0.2 gives apps the host's change staging,
  so app settings are reviewed and applied with automatic rollback like any
  other page (ADR-0004); `@nuci/app-kit` builds apps with the same
  components as NuCI itself (docs/app-sdk.md).

## Fixed

- After a reboot (restore, firmware upgrade, Reboot page) the interface could
  hang on "Loading…" instead of showing the login form.

## Tested on

- OpenWrt 25.12.0 armsr/armv8 (QEMU): full end-to-end suite on both
  realtime transports against the Image Builder image with the release
  packages, accessibility scan, throttled load check, every app against its
  real backend, every page in all three languages.
- Installation of the signed feed (`nuci` and the four apps) on an
  unmodified 25.12.0 armsr/armv8 image.
- x86/64 (QEMU): the full suite passed during development; the final
  packages were not re-tested there (they are architecture independent).
- Not yet on physical hardware.

## Known limitations

- A protocol installed while the network service runs (e.g. WireGuard right
  after `apk add`) is only known after restarting the network service or the
  router; NuCI pages say so.
- Transfers are limited to 60 seconds (uhttpd `script_timeout`), which
  covers firmware uploads on LAN but not very slow links.
- Firmware flashing itself is tested manually only.
