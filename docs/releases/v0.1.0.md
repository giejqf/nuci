# NuCI 0.1.0

First release of NuCI, a new web interface for OpenWrt 25.12. It does not use
or depend on LuCI and can be installed next to it.

## Install

```sh
# on the router (OpenWrt 25.12, apk)
wget -O /etc/apk/keys/nuci-feed.pem \
  https://github.com/<owner>/nuci/releases/download/v0.1.0/nuci-feed.pem
echo https://github.com/<owner>/nuci/releases/download/v0.1.0/packages.adb \
  >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add nuci
```

Then open `http://<router>/nuci/`. Without LuCI, `/` redirects to NuCI
(disable with `uci set nuci.main.root_redirect=0`).

## What's in it

- **Status:** overview with live data, system and kernel logs (live follow),
  processes (with signals), realtime graphs (load, CPU, traffic, wireless,
  connections).
- **System:** general settings (hostname, time zone, NTP, logging),
  administration (password, SSH, keys, web server), software (apk), startup
  (init scripts, rc.local), backup / restore, firmware upgrade, reboot.
- **Network:** interfaces (static, DHCP, DHCPv6, PPPoE), devices (bridges,
  VLANs), wireless (radios, networks, scan and join, stations), DHCP & DNS,
  hostnames, static routes, diagnostics.
- **Firewall:** defaults with ruleset preview, zones and forwardings, port
  forwards, traffic rules, NAT rules.
- **Safety:** every change is staged, reviewed and applied with automatic
  rollback; the device must stay reachable on the address you use, checked
  by the router itself (ADR-0002), before a change is confirmed.
- **Realtime:** Server-Sent Events with automatic fallback to polling; nothing
  runs in hidden tabs (ADR-0001).
- **Extensions:** `@nuci/app-sdk` for `nuci-app-*` packages
  (see docs/app-sdk.md).

## Known limitations

- Root login only; ACLs are honoured but there is no user management.
- English only (translations can be added with `pnpm i18n:template`).
- `file.read` in rpcd limits backup downloads to 256 KiB archives.
- Firmware flashing is tested manually only.
