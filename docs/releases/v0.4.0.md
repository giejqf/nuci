# NuCI 0.4.0

NuCI is a web interface for OpenWrt 25.12 that does not use or depend on LuCI.
0.4 adds a first-run setup wizard, firmware upgrades through the OpenWrt
build service, traffic accounting and ad blocking, and removes the remaining
limits of 0.2. (0.3 was not released separately.)

## Install

```sh
# on the router (OpenWrt 25.12, apk; any architecture)
BASE=https://github.com/giejqf/nuci/releases/download/v0.4.0
wget -O /etc/apk/keys/nuci-feed.pem "$BASE/nuci-feed.pem"
echo "$BASE/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add nuci                      # the interface
apk add nuci-app-adblock          # optional apps, see below
```

Then open `http://<router>/nuci/`. Upgrading from 0.2: replace the
repository line with the 0.4.0 one, then `apk update && apk upgrade`.

## New

- **Setup wizard.** On a router without a root password NuCI opens a short
  wizard after login: password, internet connection (DHCP, static or PPPoE),
  Wi-Fi, time zone and host name, applied together with automatic rollback.
  System → Setup wizard opens it any time.
- **New apps** (separate packages; each pulls in its OpenWrt backend):
  - `nuci-app-asu`: System → Firmware upgrade. Checks the OpenWrt build
    service for a newer release, has an image built with the router's
    packages, downloads, verifies and installs it with the settings kept.
    NuCI is carried across the upgrade and reinstalled from its feed
    afterwards when one is configured (ADR-0007).
  - `nuci-app-nlbwmon`: Status → Traffic usage. Traffic per device and per
    protocol for the current or an earlier accounting period, with the
    accounting settings.
  - `nuci-app-adblock`: Services → Adblock. Blocklist feeds and categories,
    your own block- and allowlist, safe search, forced local DNS, statistics
    and a domain lookup.
- **Protocols after install.** When a protocol package (e.g. `ipip`,
  WireGuard) was installed after the network service started, Network →
  Interfaces says so and restarts the service on request. IPIP tunnels are
  new.
- **Transfers of any duration.** Firmware and backup uploads and backup
  downloads go in resumable chunks, so slow links are no longer cut off
  after 60 seconds (ADR-0005).
- **Apps in your language.** App menu entries are translated too
  (`@nuci/app-sdk` 0.4).

## Fixed

- Add dialogs (port forwards, rules, Wi-Fi networks, …) no longer leave a
  half-filled entry behind when cancelled; *Done* shows every missing field.
- Tables stack into cards on phones; row actions stay reachable.
- The overview lists radios whose networks are all disabled.
- Software: searching works after a reboot (the package lists are
  downloaded first when they are missing).
- Status pages no longer pile up requests on a busy router.

## Tested on

- OpenWrt 25.12.0 armsr/armv8 (QEMU, GitHub Actions on every change): the
  full end-to-end suite on both realtime transports against the Image
  Builder image, accessibility scan, every app against its real backend,
  every page in all three languages, and a real attended sysupgrade of the
  lab image (against a local stand-in for the build service).
- By hand: an attended sysupgrade 25.12.0 → 25.12.5 through
  sysupgrade.openwrt.org on armsr/armv8.
- Not yet on physical hardware.

## Known limitations

- The firmware upgrade reinstalls NuCI from its feed only when the feed is
  configured on the router (as in the install steps above).
- Adblock's DNS report (needs `tcpdump`) is not shown.
