# NuCI 0.5.0

NuCI is a web interface for OpenWrt 25.12 that does not use or depend on
LuCI. 0.5 adds five apps and a new look. (This release also carries the
0.4 changes: the 0.4.0 tag was never published, see
[v0.4.0.md](v0.4.0.md).)

## Install

```sh
# on the router (OpenWrt 25.12, apk; any architecture)
BASE=https://github.com/giejqf/nuci/releases/download/v0.5.0
wget -O /etc/apk/keys/nuci-feed.pem "$BASE/nuci-feed.pem"
echo "$BASE/packages.adb" >> /etc/apk/repositories.d/customfeeds.list
apk update
apk add nuci                      # the interface
apk add nuci-app-wol              # optional apps, see below
```

Then open `http://<router>/nuci/`. Upgrading: replace the repository line
with the 0.5.0 one, then `apk update && apk upgrade`.

## New

- **A new look**, following the dashboard design: a quieter palette in light
  and dark, flat cards, a sidebar with a settings search and foldable
  groups, a breadcrumb in the top bar, and an apply bar at the bottom that
  shows the number of unsaved changes. The login page shows the router's
  name and model. The overview opens with an "Internet is working" card
  (WAN state, address, live download and upload) and tiles for devices,
  CPU, memory and uptime (ADR-0008).
- **New apps** (separate packages; each pulls in its OpenWrt backend):
  - `nuci-app-https-dns-proxy`: Services → DNS over HTTPS. Resolver
    instances from provider presets or your own URL, which dnsmasq uses them,
    and the running state.
  - `nuci-app-wol`: Services → Wake on LAN. Saved targets, wake a target or
    a known host.
  - `nuci-app-frpc`: Services → frp client. Server connection, proxies and
    their live state, start/stop and start at boot.
  - `nuci-app-minidlna`: Services → Media server. Settings, media folders,
    library counts, connected players and a rescan.
  - `nuci-app-uhttpd`: System → Web server. Listeners, limits, the
    certificate (details and a new one on request). A change that cuts off
    the browser rolls back like any network change.
- Plus everything in 0.4: the first-run setup wizard, firmware upgrade
  through the OpenWrt build service, traffic usage, Adblock, protocols
  after install, resumable transfers.

## Not in this release

Speed test, per-device traffic columns and Wi-Fi QR codes from the design
need data the router does not provide yet.

## Tested on

- OpenWrt 25.12.0 armsr/armv8 (QEMU): the end-to-end suite against the lab
  image, accessibility scan in both themes, every app against its real
  backend (DoH through a local stub, frpc against a local frps, a magic
  packet counted on the wire), pages in all three languages.
- Not yet on physical hardware.

## Known limitations

- Same as 0.4: the firmware upgrade reinstalls NuCI from its feed only when
  the feed is configured on the router; Adblock's DNS report needs `tcpdump`.
- The wizard, wireless and interface pages keep their earlier structure with
  the new look.
